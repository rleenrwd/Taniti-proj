# Discover Taniti

A responsive tourism website prototype for the fictional island of Taniti, designed to help visitors explore accommodations, transportation, entertainment, and essential travel information through a clear and accessible interface.

## Live Demo

https://rleenrwd.github.io/Taniti-proj/

## Design Process

The project began with UX planning and wireframing to establish the site's initial information architecture, navigation, page layouts, and user flows. The design was then evaluated through user testing, including guerrilla usability testing, with feedback used to refine the interface, content organization, and overall user experience. As a result, the final responsive website intentionally evolved from the original wireframe shown below.

## Overview

Discover Taniti was developed as a UX and front-end web development project focused on designing an intuitive travel experience for visitors to the fictional island of Taniti.

The project translates user and business requirements into a responsive, multi-page website that organizes key travel information and provides clear navigation across the visitor experience.

## Features

- Responsive desktop and mobile layout
- Lodging and accommodation information
- Transportation options
- Entertainment and activity information
- Visitor FAQ and travel information
- Trip reservation interface
- Consistent navigation across multiple pages
- Accessible semantic HTML structure and image alternative text

## Technologies

- HTML5

## Project Focus

This project focused on applying UX and front-end development principles to a complete website prototype, including:

- Information architecture
- Responsive interface design
- User-centered navigation
- Visual hierarchy and consistency
- Translating requirements into an interactive prototype
- Designing for desktop and mobile experiences

## Project Structure

- `index.html` — Home
- `about.html` — Island information
- `lodging.html` — Lodging options
- `transportation.html` — Transportation information
- `entertainment.html` — Activities and entertainment
- `faq.html` — Visitor FAQs
- `reserve.html` — Reservation interface
- `styles.css` — Custom styling
- `assets/` — Images and supporting assets
